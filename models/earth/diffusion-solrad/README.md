# Diffusion_SolRad

## 1. 模型介绍

Diffusion_SolRad 是面向太阳辐射短临预报的条件扩散模型。模型基于修改后的 MCVD/DDPM 框架，综合使用 Himawari 卫星晴空指数、WRF 辐射预报和地形信息，生成未来太阳辐射空间分布。

本目录复现的是仓库提供的 **1小时太阳辐射预测模型**，输出未来6个时间步，每个时间步的空间分辨率为512×512。

## 4. 安装依赖

    python -m pip install -r requirements.txt

## 5. 下载权重和样例数据

    python download_assets.py

下载内容包括：

- 1小时预测模型权重；
- 3个官方样例数据文件。

## 6. 运行推理

    python inference.py \
        --pred-hr 1hr \
        --pred-mode DDIM \
        --ddim-steps 100 \
        --basetime 202504131100 \
        --device auto \
        --seed 42

另外两个样例时间：

- 202504161200
- 202507151200

## 7. 输入与输出

主要输入字段：

- Himawari：历史卫星晴空指数；
- WRF：数值天气预报条件；
- topo：地形特征；
- clearsky：晴空太阳辐射；
- time_feat：时间特征。

正式测试输出形状：

    [1, 6, 512, 512]

其中6表示未来6个时间步。
