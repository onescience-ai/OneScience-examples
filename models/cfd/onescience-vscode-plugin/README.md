# OneScience 插件

OneScience 插件面向科学计算与模型开发场景，提供从项目初始化、资源查看到集群连接配置的一体化能力，帮助你在 IDE 内快速完成常见工作流。

## 核心功能

### 1. 一键安装与环境初始化

- 自动拉取并更新 OneScience 所需资源（如 oneskills）。
- 自动安装并配置 scnet 与 cluster-cmd 相关能力。
- 自动写入当前 IDE 的 mcp.json，减少手工配置成本。

### 2. OneScience Explorer 导航面板

- 内置分层导航：快速开始、项目、工作台、资源、设置。
- 提供教程与文档入口，便于快速上手。
- 支持查看已安装技能与相关文档。

### 3. 项目工作流支持

- 一键下载 onescience 项目到当前工作区。
- 快速定位并打开项目目录。
- 支持在侧栏中直接触发常用操作，减少命令切换。

### 4. 智能体与技能

- 「创建 Agent」：在 VS Code 中安装聊天用智能体说明；Trae / Trae CN 可走官方导入流程。
- 「创建 项目 skill」等会将说明复制到剪贴板，便于在 AI 聊天中粘贴使用。

### 5. 配置与连接管理

- 统一设置面板，集中管理 SSH、MCP、项目配置。
- 支持默认 SSH Host 管理，方便集群相关任务配置。

### 6. 清理与可维护性

- 提供清理命令，清除当前 IDE 下的 OneScience 相关数据。
- 保留安装状态与日志能力，便于定位问题。

## 安装与启动

### 安装

1. 在扩展市场安装 OneScience 插件。
2. 打开任意工作区。
3. 插件激活后会自动进行安装检查与必要初始化。

### 手动触发

可通过命令面板执行以下命令：

- Activate OneScience Plugin
- Download OneScience Project
- Clean Up OneScience Plugin Data

## 推荐使用流程

1. 打开工作区并等待插件完成初始化。
2. 在 OneScience Explorer 中进入“快速开始”查看教程。
3. 执行“下载项目”并在本地开始开发。
4. 在“设置”中完成 SSH 与 MCP 相关配置。
5. 按需使用「创建 Agent」或复制到剪贴板的技能说明，在 AI 聊天中继续协作。

## 系统要求

- 建议安装并可在命令行中使用 git。
- 建议具备可访问资源仓库的网络环境。
- 若使用集群能力，请确保本地 ssh 可用并已配置凭据。

## 常见问题

### 初始化失败怎么办？

- 先检查 git 是否可用。
- 检查网络是否可访问相关仓库与下载地址。
- 查看插件输出面板日志定位失败步骤。

### 清理会影响其他 IDE 吗？

- 不会。清理命令仅作用于当前 IDE 的 OneScience 数据与配置。

## 关于兼容性

插件支持在多个主流 IDE 中安装与运行（如 VSCode、Trae）。兼容性设计已内置在架构中，日常使用无需额外配置。
